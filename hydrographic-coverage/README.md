# FINN Hydrographic Coverage Tracker

This public research project tracks authoritative U.S. hydrographic and bathymetric coverage from public government sources.

It is intentionally independent of FINN's private S-100 implementation repositories. The collector runs entirely in this public repository against public source services, and the website consumes only the public artifacts produced here.

## Sources

- NOAA Office of Coast Survey — published ENC cell footprints by usage band.
- U.S. Army Corps of Engineers — Inland ENC coverage.
- U.S. Army Corps of Engineers eHydro — authoritative survey footprints; **not ENC coverage**.
- U.S. Geological Survey / 3DEP — inland bathymetry survey inventory; **not ENC coverage**.
- Natural Earth — public-domain overview basemap used for rendering.

## Public artifacts

`public/coverage-summary.json`
: Current source counts and classifications.

`public/latest-changes.json`
: Latest meaningful NOAA published-inventory change observed by the tracker.

`public/history.json`
: NOAA published-inventory observations. Unchanged refreshes are not appended.

`public/assets/hydrographic-coverage.png`
: Rendered overview atlas generated by the workflow.

Large source GeoJSON files are fetched and generated during the workflow but intentionally not committed. They are reproducible working data and would unnecessarily inflate repository history.

## Automation

`.github/workflows/hydrographic-coverage.yml` runs weekly, can be started manually, and runs when the collector or feed-builder changes. It requires no private-repository token and no AWS credential. GitHub's repository-scoped workflow token is used only to commit refreshed public artifacts back to this public repository.

## Security boundary

The public tracker has no dependency on, credential for, or read path into private FINN engineering repositories.

```text
NOAA / USACE / USGS public services
              ↓
   field-notes GitHub Action
              ↓
      public tracker artifacts
              ↓
         FINN website
```

Public consumers never reach into private FINN repositories.

## Important distinction

NOAA ENC and USACE Inland ENC are navigation-grade authoritative electronic chart coverage. USACE eHydro and USGS inland bathymetry are authoritative supplemental survey/bathymetric footprints and must not be represented as ENC coverage.

This project is a coverage research artifact, not a navigation chart.
